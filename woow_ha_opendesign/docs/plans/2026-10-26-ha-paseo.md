# HA Paseo integration implementation plan

**Goal:** Prepare add-on 0.2.7 with the shared native Paseo launcher, persistent managed runtime and authenticated HA Ingress routes.

**Architecture:** The reviewed shared core supplies the native launcher and atomic MCP CAS API. Both wrappers install the same immutable 0.2.1 runtime package; HA runs its bridge in the same container/PID namespace and UID as OpenDesign. Nginx gates HA routes by Supervisor peer, overwrites proxy context, and reaches the bridge on a private Unix socket. Runtime authorization validates user, exact ingress prefix, public Host, Origin and mutation Referer without trusting forwarded headers.

**Tech Stack:** Node 22, Express, nginx, Bash/tini, npm lockfiles, Node test runner.

1. Runtime: add `host/ha-ingress.mjs`, explicit HA config/socket startup, request authorization injection, and prefix-aware setup HTML/JS. Add HTTP rejection tests and retain existing PaaS and manual-stop/onboarding tests. Bump package to 0.2.1 and commit in own runtime branch.
2. Packaging: vendor a reproducible npm pack of that commit with SHA-256/source provenance; install dependencies with npm ci. Add bridge child, persistent state directories and private socket directory. Keep immutable core pin unchanged until main delivers the real digest; enforce native launcher/MCP build contract so the old core cannot pass.
3. Proxy: add protected `/paseo/` and `/api/paseo-bridge` locations; replace/clear forwarded context, retain Origin, reject prefix/method/path attacks. Extend the existing ingress shim for native window.open launch URLs. Test a real nginx fixture plus UI route tests.
4. Release preparation: bump 0.2.6 to 0.2.7, document onboarding, account login, manual stop, persistence, trust and release gate. Run local non-container validation and runtime tests. Commit own branch only; hand main exact SHAs/package hashes and unmet core/live checks. No publication, merge or live environment writes.

Evidence is private and only under `full-channel-release-20261026/ha`; existing checkouts stay untouched.
