每次新設定都需輸入網址及帳密。密碼直接用於登入，不寫入對話或插件狀態。

引擎與模型

Omnigent 登入與模型供應商授權分開。Claude Code／Codex 可在 Pi Agent 終端完成官方登入；Pi 可在 Models 設定供應商。

claude auth login --claudeai
codex login --device-auth

以下驗證會建立短測試對話並使用模型額度；登入及重新整理不發送模型訊息。

本頁由 HA addon 提供，保持 Pi Web 0.12.0。可在 Pi Web Plugins 停用或移除 Omnigent；重啟不會將移除的插件裝回。
