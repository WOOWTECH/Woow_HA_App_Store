WOOW 50 application prototypes

Node.js 22+ and Python 3 are required. Application code uses only Node standard libraries.
Run acceptance: bash harness/check.sh
Build downloads: python3 harness/package.py
Run preview: node server.mjs (default 127.0.0.1:18750)
Run one application: cd projects/p01 && npm test && npm start
See README.md for browser checks, IDE/Omnigent integration and known limitations.
