Core application and runtime fixes are supplied by the suite unchanged; this
directory contains tooling only. It contains no saved login, token, SSH key,
browser state, screenshot, conversation, private baseline or historical report.
Optional live IDE/Omnigent verification is separate from the core check and must
never be counted as passed merely because the core checks pass.
