# HAOS Enrollment Bridge

Connects Dnsmasq-DHCP lease snapshots to Home Assistant candidate events through a durable, MAC-based delivery ledger.

See [DOCS.md](DOCS.md) for configuration and operation. The full source, automation installers, tests, and rollback material are maintained at [WOOWTECH/haos-enrollment-bridge](https://github.com/WOOWTECH/haos-enrollment-bridge).
